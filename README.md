# TAMM Experiment Code Snapshot

This directory is a clean code snapshot prepared on 2026-06-07 for a GitHub repository.

It contains experiment code, configurations, tests, and selected runnable scripts derived from the local TAMM research workspace. It intentionally excludes manuscript files, paper figures/tables, generated results, logs, datasets, packet captures, and model checkpoints.

## Contents

- `src/`: core data adapters, feature extraction, models, training, evaluation, and utilities.
- `scripts/`: selected experiment and pipeline entry points.
- `configs/`: configuration files for datasets, models, calibration, and experiment settings.
- `experiments/`: selected auxiliary experiment utilities.
- `tests/`: lightweight tests.
- `requirements.txt`: Python dependencies from the local project.

## Notes

- Raw datasets and PCAP files are not included.
- Generated result tables, figures, and paper-specific artifacts are not included.
- Third-party repositories are not vendored here; install or clone them separately when required by a specific baseline script.
